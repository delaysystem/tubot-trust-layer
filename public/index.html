Zero-Knowledge Trust Architecture

How TuBot Trust Layer ensures sensitive data never leaks to frontier models or unauthorized storage:

1

Hybrid Detection

Microsecond regex pre-scans structured tokens (credit cards, SSNs, emails) alongside Llama 3.1 8B + Rust/Wasm + OpenRedaction on Workers AI for semantic context (names, addresses).

2

AES-256-GCM Encryption

Each sensitive entity is encrypted with Web Crypto BoringSSL using a client-held 256-bit symmetric key. Authenticated encryption prevents tampering.

3

Cloudflare D1 Persistence

Encrypted ciphertexts and initialization vectors are stored in D1. The decryption key is NEVER stored in the database or server logs.

4

Deterministic Unmasking

When the downstream LLM produces responses containing replacement tokens, the client supplies their key to seamlessly rehydrate the original entities.
